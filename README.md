
# Agentic Human-AI Interaction

Universität Ulm – Wintersemester 2026/27

## Projektziel
Entwicklung eines KI-Agenten zur Tages- und Reiseplanung
mit simulierten Datenquellen.

## Installation
Python 3.11 oder neuer wird benötigt.

Pakete installieren:
pip install -r requirements.txt

## Programmstart
python -m agent "Was steht am 29.10.2026 im Kalender?"

## Konfiguration
Die Konfiguration erfolgt über eine lokale .env-Datei.
API-Schlüssel werden nicht im Repository gespeichert.
